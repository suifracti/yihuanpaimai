# 截图列表删除功能

每张原图标题旁新增“删除截图”，本局仓库和历史详情使用同一功能。删除后更新数量，当前界面提供“撤销删除”，同时刷新同一对局的另一个截图列表。操作按对局 ID 与证据 ID 定位，不能删除其他对局的截图。

采用持久化列表移除：索引记录 removedFromGalleryAt，刷新或重启后仍然隐藏。原始文件及历史账单证据保留，不执行物理文件删除，也不改变结算金额、预测或其他对局引用。界面提示和删除按钮说明中明确这一点。再次主动保存同一张图会恢复它在列表中的显示。

验证：14 项后端测试通过，包含删除／恢复的桥接路由、跨局隔离、共享原图保留、重新加载后隐藏、再次保存恢复及已有文件存储回归。前端事件测试验证删除按钮、撤销按钮均发送正确的对局和证据 ID。
