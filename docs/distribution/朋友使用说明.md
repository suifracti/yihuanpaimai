# 异环拍卖助手：朋友使用说明

## 启动

解压完整软件目录，双击 `异环拍卖助手.exe`。首次运行会在当前 Windows 用户自己的应用数据目录建立独立数据，不会读取或覆盖开发机的 `D:\yihuanpaimai`。

## 局内使用

进入拍卖后，沿用工作台现有的手填方式记录已知情报；不需要为了保存截图逐件填写结算字段。

任何时候都可以点击工作台的“手动截图（异环）”。它只截取异环游戏客户区，不受结算场景、识图完成或填写结算表限制；每张图都会自动归入当前对局，保存结果会显示文件位置。

## 结算截图

结算画面出现后，也可以点击工作台的“保存结算截图”。它只保存当前游戏客户区的原始分辨率画面，不等待 OCR、均价或藏品身份识别。保存成功后页面会显示保存结果和相对位置。若只想留图，结算窗口里的成交价、实际总价、竞得者等字段可以全部留空，选择“仅保存本局并开始下一局”，本局会作为草稿保留。

如果仓库需要滚动，沿用“采集完整仓库”入口；每个安全视口会作为同一局的补充原图保存。没有覆盖到的部分仍会标为未覆盖，不会凭空补齐。

## 查看与导出

在“历史对局”中选择一局，可查看已保存的结算原图；手动截图也会作为同一局的原始附件随记录保存。勾选记录后可点击“删除所选”，也可以使用“全选”；删除当前正在进行的对局会被安全拒绝。点击“导出全部记录（含图片）”，选择 ZIP 保存位置；它会导出全部本地对局及其原始图片。收到别人的 ZIP 后，点击“导入对局包”选择它；已有相同记录会跳过，冲突记录会拒绝覆盖。ZIP 内含结构化记录、原始图片、已有附件和 `manifest.json`，换目录或电脑后仍按相对路径关联。

未知藏品、缺少均价或未完成结算的对局也可以保存和导出。原始图片只是后续识别依据，不会自动变成正式图鉴源卡。
