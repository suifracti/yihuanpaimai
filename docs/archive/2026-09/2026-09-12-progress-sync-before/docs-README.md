## 目录用途

| 目录 | 内容 |
| --- | --- |
| `plans/` | 开发规划、推进记录 |
| `contracts/` | 数据契约和 JSON Schema，修改实现时需同步核对 |
| `distribution/` | 面向使用者的交付说明 |
| `reports/` | 近期验证和整理报告 |
| `audits/` | 专题审计，需结合记录日期阅读 |
| `archive/2026-08/` | 从仓库根目录归拢的 14 份旧阶段报告 |

历史报告中的代码路径以仓库根目录为基准。旧报告用于追溯当时结论，不代表当前版本验收状态。新增阶段报告放入 `reports/`，不再散落根目录。

`lab/` 是可运行的实验室入口；`experiments/` 中有当前程序实际导入的采集模块，不能按目录名称或版本号直接删除。`design/`、`assets/` 和测试夹具分别保留设计来源、产品素材和回归依据。
