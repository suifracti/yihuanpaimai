# 隔离试用启动说明

当前为候选包说明，完整试用验收尚未结束。

保留整个“异环拍卖助手”文件夹，双击其中同名 EXE；不要只复制 EXE。带隔离配置的候选包主窗口会显示“隔离试用 · 数据单独保存”。

对局、昵称和桌宠位置默认存到 `%LOCALAPPDATA%\异环拍卖助手试用\data`。更换或移动程序文件夹后仍使用这份试用数据。程序不会自动把日常 v13 历史搬进来；原 v13 程序及数据保留。已有试用记录不会因再次启动被清空。

主窗口填写“本人昵称”（赢家栏显示的游戏昵称），点击“保存昵称”。设置一次，重启继续使用；清空并保存可恢复纯画面姓名识别。核对名字时保留大小写、数字和符号。数字 UID 不用于本功能。

打开自动识别后，程序结合设置和连续赢家读数判断本人／他人；姓名冲突或证据不足显示未知。不要求每局手动填写归属。逐件藏品匹配优化留待试用后继续。

本说明不代表已验证所有实战场景；真实本人获胜录像、冻结连续识别、实际滚仓及完整性能验收仍需完成。

识别进程退出时，两端会提示当前为上次结果，点击“恢复识别”重新启动。已在9cba07e隔离候选验证无游戏待机时的退出恢复。
