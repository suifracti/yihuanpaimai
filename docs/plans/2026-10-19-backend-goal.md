## 防丢、防重复（每一步都遵守）

这个项目做了两个月，出过多次成果丢失、同一件事重做、按旧状态返工的问题。所以：

1. **开工先核对，不凭记忆**：`git fetch origin main`，读 `git log` 最近提交和 Handoff 第 2 节。要做的事如果已有提交或证据（`build/` 里的 json），直接复用，不重做、不重跑已通过的检查。
2. **做完一小步就 commit + push 到 main**，推完读回 GitHub 确认到达。不把成果长时间留在本机未提交、另一个工作树或临时目录里。
3. **不覆盖、不重置**：不 `reset --hard`、不 `clean`、不强推 `main`、不整文件覆盖别人的改动；并行修改按行为合并，保留双方成果。
4. **原图和证据只增不删**：`data/videos/`、`data/reference-crops/`、`build/t1-*` 的原图、日志、证据保留；新一局用新目录，不覆盖旧局。
5. **进度只记一处**：Obsidian `Handoff.md` 第 2 节写当前做到哪、下一步；每完成 A/B/C 中一小项就更新一次，不另建规划文件。中断后下一位接手者只看这里 + `git log` 就能继续。
