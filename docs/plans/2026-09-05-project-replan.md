### 最终目标更新：拍卖全自动循环，包含自动出价和自动下一局

**产品核心补充（2026-10-09，用户直接说明）：** 先把藏品识别做好，通过实际游戏收集数据，建立能利用所有可见信息的出价算法，包括格子数、藏品数、品质统计、具体仓库物件及轮廓推算。完整目标是识别→按局/回合留存输入与结算标签→价值估计与出价策略→自动实战→补充数据的闭环。自动操作与当前显示建议修复都是这个目标的组成部分；已有solver是可复用基础，不代表算法研发已经完成。

规划设计区分两层：价值估计层联合已确认情报、具体物件及几何/轮廓约束，对未识别部分保留候选和不确定性；出价策略层再结合价值分布、回合、已见报价、成本和资金/收益约束决定出价或放弃。全部信息是可追溯地参与计算，不把同一物件/同一情报重复相加，不把推断候选强行确认为身份；具体统计方法与策略仍属后续设计，不因本节讨论直接改数学核心。

用户进一步强调既有规则已说明、格子有限、可以推测：先找回并沿用已确定规则，用剩余空间/轮廓、数量、品质和均价共同排除不可能组合，不要求每件身份识别齐全后才能估值。单一可行结果注明推导来源，多解保留候选/价值范围；有实战分布依据再计算权重，无数据不凭空给概率。推断与直接观察分开记录，不改变当前执行任务。

**无道具观察采数路线（用户本轮重申）：** 可以只观察并放弃竞拍，在结算逐步分析仓库，积累同局事前可见信息与事后可见清单；不以买下藏品或消耗道具作为建立数据集的前提。这是完整产品的常规采数模式，与实际自动竞拍模式并存。放弃动作与观察过程需在后续自动流程中实现，本轮不据此启动游戏。没有用道具不代表没有入场等费用，未实际获得的物件也不能记为本人资产。

基于合格结算标签，可在离线实验中仅暴露符合既有游戏规则的一部分统计/轮廓信息，生成明确标记的模拟道具提示，比较无提示与加入提示后的估值误差和候选收缩。其用途是研究信息价值、训练和评估融合方法；不能把推导提示混进真实使用记录，不能证明道具实际识别可靠或实战收益提升。完整真值始终隔离为标签，部分仓库只能贡献相应局部标签；不因要整仓训练而丢弃已确认的局部实例。旧历史按原资格复用，独立对局划分训练与评估，避免同局不同视口跨集合泄漏。

## 4. 结算80秒策略

首次检测到结算页起计时，同时读游戏剩余时间，以更早截止时间为准。以下是待验收目标，不是当前已达到的性能。

| 预算 | 执行 |
|---|---|
| 0–5秒 | 保存首图，定位仓库/倒计时；账单终态识别独立运行 |
| 最迟30秒 | 优先采完整仓库原图：定位顶部，逐段滚动，稳定帧落盘，保留重叠，确认底部 |
| 全仓完成后至65秒 | 后台识别已采物品；疑难项左键打开详情，读名称/品质/价格，关闭并核对原位置 |
| 65–70秒 | 必要补页、账单复核、持久化检查并关闭详情 |
| 70秒以后 | 停止新增主动操作，预留退出余量；离开后继续离线识别 |

- 每页先落盘再昂贵匹配；账单不等待仓库完成。
- 顶部、底部、中间连续覆盖都证明后才显示“整仓截图完整”；物理分件、品质、身份完成度分开。
- 优先疑难/缺参考/冲突物品详情，所有品质都纳入，不因低价值忽略。
- 输入前后核对游戏前台、场景、目标位置与剩余时间；只执行采集所需操作，不触发出售等状态变更。
- 失焦、用户接管、滚动不动时暂停；恢复后补缺页。同局首次失败不永久禁止重试。
- 时间不足仍保存已采证据和缺口；未知不算0，不用总价凑身份。
- 结算金额按标签位置、动画终态、多帧一致性核对；支持0收益、负收益、不同字段相等，不按数值去重丢字段。
- 结算记录与返回/补货流程分离。仪器配置不等于消耗，点击补货不等于成功；本局用量及上一局遗留按证据归属。未观察到成功时保留待核对，不自动购买。
