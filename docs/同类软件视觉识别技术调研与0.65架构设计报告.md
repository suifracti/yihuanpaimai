## 二、5 款主流软件深度剖析

### 1. 【竞拍之王老头计算器 / B站UP计算器】
* **技术栈**：网页端 (`index.html`) + Python Tkinter/PyQt 桌面端 (`B站UP竞拍之王计算器.exe`)。
* **视觉与算法方案**：
  * **均格数学反推**：核心逻辑为利用浮点区间 $[avg, avg + 0.01)$ 与循环步长 $d \in [1, 20]$ 求解整数总格数；
  * **OCR 识别**：采用基于 Tkinter 的外置 `ocr_worker` 抓取屏幕并识别数字。
* **优缺点评估**：
  * **优点**：数学模型小巧，区间投影法对浮点显示截断很敏感；
  * **致命缺陷**：无法应对异环复杂的离散价格池与多品质联合约束，没有概率赋权，更没有博弈出价决策。

---

### 2. 【小吱助手 AuctionPilot-Full-v0.10.19】（专攻异环拍卖的视觉天花板）
* **技术栈**：.NET C# 原生单文件编译桌面应用（大小 284MB）。
* **核心视觉工程拆解**：
  * **硬件截屏（`D3D11Capture`）**：调用 `Windows.Graphics.Capture` 与 Direct3D 11，33ms（30 FPS）后台静默抓帧，显存零拷贝，性能损耗近乎为 0。
  * **自适应坐标系（`BoardRect`）**：采用归一化比例参数：
    ```json
    "BoardRect": { "X": 0.685, "Y": 0.228, "Width": 0.29, "Height": 0.468 }
    ```
    自动适配 1080P、2K、4K 及带鱼屏。
  * **字模毫秒级匹配（`BidGlyphs` / `RoundDigits`）**：预存 59 个游戏字体渲染切片，直接进行二值化像素比对，耗时 `< 1ms` 且 100% 零错率（彻底摒弃通用 OCR）。
  * **5×5 占格形状矩阵（`Shape`）与滚动门控**：在 `catalog.json` 中定义 227 件藏品的 25 位 0/1 形状矩阵（如 `1100011000...`）；配合 `ScrollbarVision` 识别滚动条，**向上滚回顶部时自动冻结扫描**，彻底解决了实战中画面回滚导致数据被破坏的难题。
* **优缺点评估**：
  * **优点**：拥有**业内最顶级的异环原生视觉工程**，交互丝滑；
  * **致命缺陷**：**只有眼睛、没有大脑**。估值极其死板（未知红品一律算 5W），无逆向约束求解器，完全缺失对手成交价（Market Model）与博弈决策。

---

### 3. 【MaaNTE (MaaFramework)】
* **技术栈**：C++ 核心库 + Python 绑定 + OpenCV。
* **视觉与自动化方案**：
  * 基于工业级 MAA 框架，构建流水线任务调度（Pipeline Task）；
  * 采用经典的 OpenCV 模板匹配（`TemplateMatch`）、颜色直方图（`ColorMatch`）与特征点比对。
* **借鉴价值**：证明了**模板特征比对在固定游戏 UI 场景下的高稳定性和极低资源占用**。

---

### 4. 【NTE Drive Calc】
* **技术栈**：Python (PyInstaller 打包) + PySide6 + RapidOCR (ONNX/OpenVINO) + SQLite。
* **视觉方案**：
  * 本地集成 PaddleOCR / RapidOCR 的 ONNX Runtime 和 Intel OpenVINO 加速推理；
  * 专用于大批量扫描驱动盘的复杂属性文字。
* **借鉴价值**：为我们处理非固定字模的**复杂动态中文文本（如特殊场地规则描述、仪器长说明）**提供了极佳的轻量 ONNX 方案参考。

---

### 5. 【ok-nte (OneKey)】
* **技术栈**：WebView2 现代前端 UI + Python 后台 + OpenVINO AI 检测。
* **架构设计**：
  * 采用微软 **Edge WebView2** 作为渲染壳，前端完全使用现代化 Web 技术（HTML/Vue/CSS），后台通过 Python 驱动各种自动化任务与多进程通信。
* **借鉴价值**：完美验证了我们 **“保留现代化 HTML/CSS/JS 极佳界面 + 包装轻量桌面壳”** 的技术路线可行性与前瞻性。

## 四、0.65 可视化大重做的终极架构设计（“顶级眼睛 + 顶级大脑”）

0.65 的核心理念是：**全面吸收 AuctionPilot 卓越的视觉工程，无缝装载 v0.6 的量化决策大脑！**

```mermaid

        WGC --> ROI[归一化相对坐标裁切]
```

## 五、0.65 落地实施关键技术规范

### 1. 屏幕捕获与分辨率自适应
* 采用 `Windows.Graphics.Capture` (Direct3D 11) API，实现无感 30 FPS 截屏；
* 定义自适应归一化锚点坐标，全面适配 1080P、2K、4K、全屏与窗口化。

### 2. 识别算法组合拳
* **数字区（叫价、均价、总价、Q值）**：采用 `Assets/BidGlyphs` 与 `RoundDigits` 字模像素比对，1ms 级响应，100% 准确；
* **仪器与技能区（紫色以上）**：采用发光色相初筛 + 关键语义正则映射；
* **藏品图鉴区**：复用 227 件藏品的 5×5 占格形状矩阵，配合滚动方向门控进行无损拼接。

### 3. 数据链路与容错防护
* 识别结果实时注入 v0.6 的 `Delta Intel Manager`，增量更新不覆盖；
* 遇到视觉微小噪点无解时，自动触发 v0.6 的 `Diagnostic Solver` $\pm 1$ 容错纠错，实现自愈式稳定推演。
